# Security policy

## Supported version

Security fixes are made against the latest published release of this maintained
fork. Older releases may be asked to upgrade before a report is investigated.

## Reporting a vulnerability

Please use **Security → Report a vulnerability** in this GitHub repository so
the report remains private. Do not open a public issue for a vulnerability.

Include the affected version, Home Assistant version, a minimal reproduction
and a description of impact. Remove or replace all real account data before
attaching logs or screenshots.

Never submit:

- phone numbers, electricity-account numbers, names or addresses;
- QR codes, cookies, authorization headers or login tokens;
- passwords, full config entries or raw API response bodies.

The maintainer will acknowledge a complete report when possible, validate it
privately and coordinate a release before public disclosure.

## Scope

Reports about this integration's credential handling, log redaction, request
routing, cryptography use or dependency exposure are in scope. Availability or
behavior of China Southern Power Grid's own service must be reported to its
operator unless this integration creates additional security impact.
